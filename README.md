# 本地文件智能整理器

> ⚠️ 个人测试项目，界面和交互仍在迭代中，不保证生产可用。

一个本地运行的文件整理工具。扫描指定文件夹，根据文件名、扩展名等信息自动分类，生成整理方案，经确认后执行移动操作。所有操作可撤销。

## 功能

- **扫描**：递归扫描指定目录，收集文件元数据
- **分类**：基于扩展名 + 文件名启发式规则分类，可选 AI 辅助
- **整理方案**：生成分类到目标目录的移动方案，自动处理重名冲突
- **安全执行**：移动前安全检查，冲突策略可选（跳过/重命名/覆盖）
- **操作历史**：记录所有操作，支持一键撤销
- **AI 辅助**：可配置 LLM API，对含义不明确的文件名进行智能判断

## 分类

| 分类 | 说明 |
|------|------|
| 文档 | PDF、Word、Excel、TXT、Markdown 等 |
| 图片 | JPG、PNG、GIF、SVG、RAW 等 |
| 视频 | MP4、MOV、MKV、AVI 等 |
| 音频 | MP3、WAV、FLAC、AAC 等 |
| 压缩文件 | ZIP、RAR、7Z、TAR、ISO 等 |
| 安装包 | EXE、MSI、DMG、APK、JAR 等 |
| 临时文件 | TMP、BAK、LOG、缓存等 |
| 开发资料 | JS、TS、PY、Java、HTML、CSS、JSON 等 |
| 工作资料 | 通过文件名关键词识别（发票、合同、报告等） |
| 个人资料 | 通过文件名关键词识别（简历、照片、截图等） |
| 其他 | 无法确定类型的文件 |

## 使用

### 方式一：启动脚本（推荐）

```bash
./start.sh
```

脚本会自动启动服务器并打开浏览器。

### 方式二：手动启动

```bash
node server.js
```

然后在浏览器中访问 http://localhost:38211

## 配置 AI

在设置中启用 AI 辅助分类，配置 API 端点和密钥。支持 OpenAI 兼容接口（如 DeepSeek）。

## 技术栈

- Node.js HTTP 服务器
- 原生 fs 模块（文件操作）
- 纯 HTML/CSS/JS（UI，无框架依赖）
